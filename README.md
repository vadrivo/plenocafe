# Pleno Café — Premium Website v1.1

Standalone React + TypeScript + Vite café website concept for Pleno Café, São Paulo.

## Included

- `public/assets/` folder for the café's own images.
- Supplied menu photograph saved as `public/assets/pleno-menu.jpg`.
- First-screen café photography.
- Expanded emotional `01 / THE PLACE` story.
- `02 / THE RITUAL` with coffee imagery and expanded copy.
- `03 / MENU` with category tabs and the supplied menu photograph.
- `04 / THE ROOM` with atmosphere imagery.
- `05 / WORD OF MOUTH` with visual social-style gallery and the verified Google rating data supplied for the business listing.
- `06 / FIND US` map area and a direct Google Maps place link for Pleno Café.
- Responsive mobile navigation and layout.
- GitHub Pages-friendly static build.

## Add more café images

Put your images inside:

`public/assets/`

Then use them in React like:

`/assets/your-image.jpg`

The supplied menu photo is already there as:

`/assets/pleno-menu.jpg`

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The website uses some external image URLs for atmosphere/reference imagery. Replace those URLs with the café's own photographs in `public/assets/` when you have them for a fully owned image library.
